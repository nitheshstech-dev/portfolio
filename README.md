## Deployment

This is a static website and can be hosted directly using **GitHub Pages**.

Recommended GitHub Pages configuration:

**Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`**

If a GitHub Actions workflow is added later, it can be switched to **GitHub Actions** deployment.
